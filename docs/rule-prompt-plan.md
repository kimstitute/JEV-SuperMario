# 공통 규칙 프롬프트 수정 계획 — 2026-09-20

## 문제와 가설

새 candidates 경로는 policy.py의 공통 게임 규칙을 상속하지 않는다. 적 접촉과 지형 충돌의 차이가 누락됐고, Noul의 ‘생존 가능한 후속 행동’에 시간 범위가 없다. 규칙의 완전성, 질문의 판정 기준, 관측 정확성을 구별해 검증한다. 프롬프트가 원인이라는 결론을 먼저 가정하지 않는다.

## 고정할 것

- 모델 jev-1.13.0, RGB 관측기, 분석/예측 상수, 행동 후보와 기계적 제외 조건.
- 상태 이력과 과거 행동, 위험에 따른 실행 간격, 두 단계 API 구조.
- Jev 최종 Choice를 그대로 실행. 안전 필터·자동 회피·다른 AI를 추가하지 않음.
- 기록된 비교 상태에는 현재 결정 이후 결과를 넣지 않음.

## 변경할 것과 실험군

1. `legacy-v2`: 기존 후보 질문을 동결한 대조군.
2. `rules-only-v1`: 대조군의 질문·criteria를 유지하고 공통 게임/관측/조작 규칙과 참조 지시만 추가. 규칙 전달 효과를 비교.
3. `rules-v1`: 같은 공통 규칙에 유한한 평가 범위와 생존/전진/회복 우선순위를 명시. 질문 정리의 추가 효과를 비교.

규칙은 `game_rules`(게임 동작), `observation_rules`(입력 의미), `control_contract`(이 실험의 조작 제한), `decision_policy`(평가 기준)로 분리한다. 거리/가속도 휴리스틱은 기존 `rules`/`forecast_rules`에 남기며 게임의 법칙처럼 제시하지 않는다. 매 요청에 규칙 버전과 실제 내용을 기록한다.

## 진행 순서와 완료 조건

1. 출처 확인: TypeSafe state/API/질문 문서와 Nintendo 원본 SMB 설명서. 매뉴얼 사실, 코드 계약, 관측 근사를 구분.
2. 중앙 규칙 모듈과 요청 빌더 통합. 후보 평가의 모든 질문과 최종 선택이 같은 규칙을 받는지 검사.
3. 회귀 검사: 입력 불변성, 두 단계 동일 규칙, 과거 상태 오염 방지, 후보/프레임 고정, 오류·예산 처리, 원본 대조군 일치.
4. 사전에 선정한 상태들에서 세 실험군을 두 번씩 평가. 장면당 base-state SHA256을 기록하고 모델, 토큰, 지연, 행동, Noul을 보존. 전진/점프 여부만으로 정답률을 만들지 않음.
5. 실제 게임 검증: 같은 파이프 상승 장면과 낭떠러지 접근 장면을 과거 버튼으로 재현. RGB와 자기 상태가 일치할 때만 새 제어를 시작. 설정 구간과 새 제어 구간의 성능을 구분.
6. 결과 기록과 최종 기본값 결정. 불리한 결과를 숨기거나 통과할 때까지 임의로 프롬프트를 조정하지 않음. 추가 변경이 필요하면 새 버전·새 비교로 분리.

## 평가 범위

- 평지, 낮은 천장의 적 접근, 파이프 접근/상승/이미 A를 놓은 상태, 낭떠러지 먼/가까운 접근, 하강·착지 직후, 미확인 지형.
- 단위 테스트의 기대값은 전송 계약·기계적 조건만 검증한다. Jev 행동의 옳고 그름은 별도 게임 결과로 확인한다.
- 한 번의 구간 통과는 전체 레벨 성능이나 확률 보정을 입증하지 않는다.

## 완료 기록

- 원본 설명서 인쇄 페이지 3~4와 8~10 확인. 일반 고체 충돌은 정성적 모델로, 공중 A 재누름 제한은 이 컨트롤러의 계약으로 분리했다.
- 세 프로필 구현, 모든 후보 질문과 두 단계 공통 규칙 전달 검사 완료.
- 전체 70개 테스트 통과. 플랫폼 간 줄바꿈 정규화 후 동결 대조군 검사도 다시 통과했다.
- 10개 고정 입력 × 3프로필 × 2회 = 60개 결정/120 API 요청. 모든 대응 입력 SHA256 일치. 한 장면의 rules-only 두 응답은 달랐으며 그대로 기록했다.
- 파이프 상승·낭떠러지 접근에서 legacy-v2/rules-v1을 각각 실제 재현했다. 네 실행 모두 초기 RGB/자기 상태가 원본과 일치했다. 네 실행 모두 해당 장애물을 통과하고 20회 결정 한도까지 생존했다.
- 기본값은 공통 규칙과 명시적 판정 기준을 가진 rules-v1로 유지한다. 단기 통과 보존과 전송 계약을 확인했으며 전체 레벨 성공률의 우위는 입증하지 않았다. 질문을 더 조정해 통과 결과를 선별하지 않았다.
